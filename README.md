# tislam93.github.io

The source for my personal website at [tislam93.github.io](https://tislam93.github.io).

I'm Taimoor Ul Islam, a Research Assistant Professor at the [Center for Wireless, Communities and Innovation](https://wici.iastate.edu/) at Iowa State University. I work on Open RAN, 6G, massive MIMO, and rural broadband.

## Stack

- [Jekyll](https://jekyllrb.com/) static site generator
- [al-folio](https://github.com/alshedivat/al-folio) theme by Maruan Al-Shedivat
- Hosted on [GitHub Pages](https://pages.github.com/), built and deployed via GitHub Actions on every push to `main`

## Layout

- `_pages/about.md` — homepage bio
- `_pages/story.md` — long-form personal narrative
- `_projects/` — project pages (ARA, ACCoRD, ArMORED)
- `_bibliography/papers.bib` — publications, in BibTeX
- `_data/cv.yml` — structured CV that renders at `/cv/`
- `_news/` — short announcements that appear on the homepage
- `_posts/` — blog posts

If you want to know how to extend or modify the site, see [`DEPLOY.md`](./DEPLOY.md).
